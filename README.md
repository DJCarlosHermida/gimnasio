# Demo Gimnasio

Sitio de planes e inscripción para un gimnasio. El interesado ve las actividades y envía la consulta o la clase de prueba por WhatsApp.

> Maqueta para mostrar a locales. Marca, zona, horarios y planes se cambian en `src/data/catalog.ts`.

## Recorrido

| Paso | Ruta | Qué pasa |
| --- | --- | --- |
| Inicio | `/` | Marca, actividades y cómo consultar |
| Planes | `/planes` | Musculación, clases, funcional y full |
| Consultar | `/consultar` | Formulario de inscripción / clase de prueba |

Horario de ejemplo: lun–vie 7:00–22:00, sáb 8:00–14:00 (Montevideo).

## Desarrollo local

```bash
npm install
npm run dev
```

Abre [http://localhost:5176](http://localhost:5176).
